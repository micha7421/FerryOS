# FerryOS branding

| File | Use |
|---|---|
| `ferryos-logo.svg` / `.png` | The emblem in teal, for light backgrounds; also the system logo |
| `ferryos-logo-on-dark.svg` | The emblem in light teal, for dark backgrounds |
| `ferryos-logo-symbolic.svg` | KDE symbolic icon; takes the color scheme's text color |
| `ferryos-lockup.svg` | Icon + wordmark on light backgrounds |
| `ferryos-lockup-dark.svg` | Icon + wordmark on dark backgrounds |
| `ferryos-ascii.txt` | ASCII logo for terminals and plain-text docs |

The colored ASCII logo for `fastfetch` lives in `system_files/usr/share/ferryos/ferryos-fastfetch.txt`.

## The logo

Six boat hulls form a ring around a sun, in a single color. The ring stands for ferries going back and forth, carrying you from one shore (Windows) to the other (Linux). Like the NixOS and Gentoo logos, it's a freestanding emblem built from simple geometric shapes, with no background tile.

Always use the emblem in one color: teal on light backgrounds, light teal on dark ones.

## Colors

| Role | Color |
|---|---|
| Teal (primary, logo on light) | `#0E8A8A` |
| Light teal (logo on dark) | `#5CC8C2` |
| Navy (text, dark) | `#12324A` |
| Sand (background) | `#F6EFE3` |
| Sunset (UI accent, not used in the logo) | `#FF8A4C` |

## Typography

The wordmark is lowercase **ferry** (navy) + **os** (teal), set in [Outfit](https://fonts.google.com/specimen/Outfit) SemiBold (SIL Open Font License) and converted to outlines.

## Regenerating

All logo files, including both ASCII logos, are generated by `generate.py`. It needs `fonttools`, `shapely` and the Outfit font file:

```bash
pip install fonttools brotli shapely
npm pack @fontsource/outfit && tar xzf fontsource-outfit-*.tgz
python3 generate.py package/files/outfit-latin-600-normal.woff
```
